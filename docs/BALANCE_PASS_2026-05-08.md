# Balance Pass - May 8, 2026

Status: work-in-progress balance note for the current `Phase 2` simulator loop.

## Scope

- normal map difficulty for `tier4` through `tier6`
- boss difficulty for `bossTier4` through `bossTier6`
- normal map sustain targets
- boss reward guarantees

## Changes made in this pass

- Added a real player targeting range and explicit enemy contact range in shared domain combat.
- Reworked normal map sustain toward approximate full-clear targets of:
  - `1.0` same-tier map per run
  - `0.25` next-tier maps per run
- Kept boss lairs out of the normal map-sustain model.
- Guaranteed at least one real boss reward on every successful boss kill.
- Added tier-specific boss multipliers instead of relying only on one broad boss formula.

## Representative simulator checks

All runs below used the current `main` balance state and the benchmark profiles generated by `npm run sim:bench`.

- `tier5Map` with `benchmark-tier5` over `100` runs
  - completion: `33%`
  - death: `67%`
  - map sustain: `0.49 maps/run`
- `tier6Map` with `benchmark-tier6` over `50` runs
  - completion: `22%`
  - death: `78%`
  - map sustain: `0.40 maps/run`
- `bossTier5` with `benchmark-tier5` over `50` runs
  - completion: `30%`
  - death: `70%`
  - guaranteed boss reward output visible in unique totals

## Current read

- `tier5Map` is close to a useful target band for same-tier progression tests.
- `tier6Map` is improved and now looks meaningfully testable, but still a bit harsh.
- `bossTier5` is in a much healthier range than earlier passes.
- `bossTier4` and `bossTier6` are still inconsistent outliers and likely need another tier-specific pass rather than one shared boss rule.

## Next follow-up

- tighten `bossTier4` and `bossTier6` independently
- decide whether the normal-map sustain targets should be raised further for late tiers after survivability stabilizes
- add tier-specific boss unique pools when the boss difficulty curve is stable enough to support farming
